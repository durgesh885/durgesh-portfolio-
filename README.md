# Durgesh Chaudhari — Portfolio Website 🚀

Welcome to my personal portfolio website! This is a premium, fully interactive, and modern developer portfolio designed to showcase my experience, skills, and projects as a Cloud & DevOps Engineer.

## 🔗 Live Site
👉 **[https://durgesh-chaudhari-portfolio.vercel.app](https://durgesh-chaudhari-portfolio.vercel.app)**

## 🛠️ Tech Stack
* **Framework:** Next.js (React.js)
* **Styling:** CSS3, Tailwind CSS
* **Animations:** Interactive Canvas, CSS Animations
* **Hosting & Deployment:** Live on Vercel

---

## 📂 Key Sections
1. **Hero Header:** A modern greeting and call-to-action to download my ATS-optimized resume.
2. **About Me:** Professional background summary highlighting MCA studies, DevOps interest, and cloud infrastructure experience.
3. **Technical Skills:** Categorized layout for Cloud Infrastructure, DevOps & Automation, Web Servers & Networking, and Development/Scripting.

## ⚡ Featured Projects Listed

### 1. AWS EC2 Self-Service Management Dashboard (Live)
* **Tech Stack:** AWS EC2 · AWS Lambda · Python (Boto3) · Amazon API Gateway · AWS IAM · Vercel
* **Details:** Serverless control panel utilizing Lambda and Boto3 API to toggle instances runtime status, saving on-demand costs. Secured via API Gateway REST endpoints and custom IAM JSON policies.

### 2. Dockerized App Deployment on AWS EC2 (Configured)
* **Tech Stack:** Docker · Docker Compose · AWS EC2 · Nginx · Ubuntu Linux
* **Details:** Multi-container runtime setup using Docker Compose inside a secure Ubuntu EC2 instance, utilizing Nginx as a reverse proxy to route public traffic to container ports.

### 3. Multi-Domain Web Server Hosting on AWS EC2 (Configured)
* **Tech Stack:** Apache (httpd) · AWS EC2 · AWS Route 53 · Let's Encrypt (Certbot) · Linux
* **Details:** Deployed multiple web profiles on a single Linux EC2 instance using Apache Virtual Hosts, managed DNS routing in Route 53, and secured traffic via Certbot SSL/TLS.

### 4. High-Availability Static Web Hosting on AWS S3 (Configured)
* **Tech Stack:** AWS S3 · AWS IAM · CORS Configuration
* **Details:** Highly scalable static asset storage utilizing S3 public web endpoints, custom JSON access policies, and CORS configuration to restrict/allow API access.

## 🚀 Getting Started Locally

### 1. Clone the repository:
```bash
git clone https://github.com/durgesh885/durgesh-portfolio-.git
cd "Durgesh Chaudhari  portfolio"
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
